# 14. Conclusion
The SOC Home Lab achieved a meaningful foundation for blue-team practice: a central Wazuh SIEM on Ubuntu,
Windows endpoint monitoring with Sysmon and the Wazuh Agent, network-device discovery through NetAlertX and
additional visual analysis through Grafana. The project demonstrates the operational concepts of telemetry collection,
detection, infrastructure troubleshooting and evidence-based incident investigation. Importantly, its historical record
also reveals a real Wazuh Manager startup problem that must be resolved and validated before the system is
presented as currently healthy.
The AI component is a credible next step, but it remains future work. The safest project narrative is therefore “SOC
infrastructure implemented and tested historically; current health and extended scenarios require revalidation; AI-
assisted triage planned for Phase 2.”
