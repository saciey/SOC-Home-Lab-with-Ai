# Evidence Register

This directory is intentionally empty of raw screenshots and exported logs. The documented scenarios are not all freshly verified.

Only add **redacted**, timestamped evidence from your own authorized lab, with the test ID, hostname, expected result, observed result, and technical interpretation. Remove secrets, personal data, hashes used as credentials, enrollment keys, session cookies, and raw auth logs before publishing.

See [Evidence Register](../reference/evidence-register.md) and [Security Validation](../09-security-validation.md).
